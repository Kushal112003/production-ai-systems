# ADR-0001: Record architecture decisions

Date: 2026-10-07
Status: Accepted

## Context

Every real technical decision in this repo gets an ADR. "Real" = it cost
more than an hour to decide, it constrains future work, or a reviewer
could reasonably disagree.

## Decision

ADRs live in `docs/adr/` as `NNNN-short-title.md`, numbered sequentially.
Each records: context, decision, alternatives rejected (with why), and
consequences.

## Consequences

- Interview answers write themselves: every ADR is a "tell me about a
  hard technical decision" story with the reasoning attached.
- Rejected alternatives are the proof of judgment, not the chosen option.
