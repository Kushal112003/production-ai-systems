# MCP gateway

Agent control plane — PoW #2 (Jan 2027).

Lands here: MCP servers wrapping REST APIs with enterprise auth, tiered
tool-call approval flows (approve / block / observe), kill switches,
audit log, and a failure matrix. The security spine follows the OWASP
five controls: segregate untrusted content, least-privilege wrappers,
validate model outputs, human approval for high-risk actions, adversarial
testing.

Not started — scheduled W15–W18.
